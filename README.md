# 俄羅斯方塊｜五關不同背景＋手機觸控版

直接放到 GitHub Pages 即可執行。

## 功能
- 上鍵旋轉（電腦仍可使用）
- 手機觸控按鈕：左移、旋轉、右移、加速、直接落下、暫停
- 五個關卡，每關不同背景
- 關卡越高速度越快
- 第 30 行完成第 5 關
- 最高分使用瀏覽器 Local Storage 保存

## 關卡
1. 星空啟程：0 行
2. 海洋世界：5 行
3. 夢幻紫境：12 行
4. 火焰挑戰：20 行
5. 翡翠王國：30 行
